# Project Structure

This repository is organized as a reproducible data science project. The raw Expedia CSV is too large for normal notebook-first work, so the workflow starts with DuckDB scripts that create smaller, inspectable tables.

```text
flight/
|-- api/                 FastAPI application for serving predictions
|-- data/
|   |-- raw/             Original downloaded data, excluded from Git
|   |-- interim/         Route-level Parquet working subsets, excluded from Git
|   `-- processed/       DuckDB database and derived tables, excluded from Git
|-- docs/                Project notes and methodology documentation
|-- models/              Saved joblib model artifacts, excluded from Git
|-- notebooks/           Optional explanatory notebooks
|-- reports/
|   |-- figures/         Generated EDA figures, excluded from Git
|   `-- tables/          Generated metric/result tables, excluded from Git
|-- scripts/             Clean pipeline entry points and detailed phase scripts
|-- sql/                 SQL analysis files
|-- src/                 Reusable Python modules
|-- tests/               Unit and smoke tests
|-- Dockerfile           API container definition
|-- requirements.txt     Python dependencies
`-- .gitignore           Keeps large/generated artifacts out of Git
```

## Reproducible Flow

Run scripts from the repository root.

```powershell
python scripts/create_route_subset.py
python scripts/learning_phases/profile_route_subset.py
python scripts/create_clean_subset.py
python scripts/create_feature_table.py
python scripts/create_model_splits.py
python scripts/learning_phases/run_phase12_baselines.py
python scripts/learning_phases/run_phase13_models.py
python scripts/learning_phases/run_phase14_evaluation.py
python scripts/learning_phases/run_phase18_price_context.py
python scripts/create_book_wait_labels.py
python scripts/learning_phases/run_phase19_book_wait.py
python scripts/learning_phases/run_phase20_uncertainty.py
python scripts/learning_phases/run_phase21_finalize_model.py
```

The API depends on `models/final_price_artifacts.joblib`, which is generated by the Phase 21 finalization script.

## Curated Pipeline

For a cleaner portfolio workflow, use the top-level pipeline scripts:

```powershell
python scripts/01_create_subset.py
python scripts/02_build_features.py
python scripts/03_train_price_model.py
python scripts/04_evaluate_price_model.py
python scripts/05_book_wait_experiment.py
```

Detailed learning scripts are preserved in `scripts/learning_phases/`.
