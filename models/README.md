# Models Directory

Saved model artifacts are generated by the phase scripts and excluded from Git.

Important generated files:

- `final_price_model.joblib`: saved preprocessing-plus-regression pipeline.
- `final_price_artifacts.joblib`: model plus price-context and uncertainty artifacts used by the API.
- `phase19_book_wait_model.joblib`: experimental BOOK/WAIT classifier.

Regenerate final artifacts with:

```powershell
python scripts/run_phase21_finalize_model.py
```
