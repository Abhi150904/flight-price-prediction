# Notebooks Directory

These notebooks are curated narrative companions for the project. They explain the reasoning and show selected evidence, while the reproducible pipeline remains in `scripts/` and reusable logic remains in `src/`.

- `01_data_understanding.ipynb`: dataset grain, scale, validity, repeated observations, and leakage risks.
- `02_eda_statistics.ipynb`: SQL-style EDA, visual findings, and the nonstop-vs-connecting statistical question.
- `03_modeling_and_evaluation.ipynb`: baselines, model comparison, grouped validation, final metrics, uncertainty, and BOOK/WAIT framing.

Run them from the repository root after generating the DuckDB database and report tables.
